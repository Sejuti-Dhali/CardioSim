# Engineering and reproducibility notes

## Origin

CardioSim is a new browser-based model inspired by the cardiovascular compartment-model concepts discussed in a 52-page BME 3114 KUET cardiovascular modeling report dated April 2024.

## Independent implementation

The original report's native Simulink model and executable solver configuration are not included. This application therefore implements its own simplified 8-compartment model.

Compartments: RA, RV, PA, PV, LA, LV, SA, SV.

Connections: tricuspid valve, pulmonary valve, pulmonary vascular flow, pulmonary venous return, mitral valve, aortic valve, systemic vascular flow and systemic venous return.

State: compartment volumes (mL).
Algebraic variables: pressures (mmHg), flows (mL/s).

Numerical method: conservative explicit Euler integration with time step 0.0015 s over a 12 s demonstration interval.

The two ends of each connection receive equal and opposite volume transfers. Total blood volume is checked numerically at each step.

## Interpretation

The website presents only values generated by its own simulation engine. No simulation result from the original report is claimed as newly reproduced or experimentally validated.

There is no claim of clinical calibration, validated pressure waveforms, numerical convergence or physiological applicability.

The next reproducibility stage would compare against a documented reference model and demonstrate parameter sensitivity, time-step convergence and appropriate physiological calibration.
